FIDOO
=====

Format Identification of Digital Objects Online
-----

A javascript library to determine the file-type and version of a file.

FIDOO can be used to check file-types before uploading or as a node.js app to analyse files on a file-system.

FIDOO uses a trimmed down and modified  [FIDO](https://github.com/openpreserve/fido/) signature version of [PRONOM](http://www.nationalarchives.gov.uk/pronom/) signature files, currently generated from PRONOM/FIDO signature release 116 (see `tools/build-signatures.js` to regenerate against a newer release).

Demo: <http://www.techmaurice.com/fidoo/>
